# Akarsh K Nair — academic website

A responsive, build-free website for https://akarshkongassery.github.io.

## Publish with GitHub Pages

1. Open or create the repository `akarshkongassery/akarshkongassery.github.io`.
2. Upload the contents of this folder at the repository root (not the enclosing folder). Review existing files before replacing them.
3. In **Settings → Pages**, select **Deploy from a branch**, **main**, and **/(root)**, then save.
4. GitHub Pages will provide the deployment status and live URL.

No package installation or build is needed. Open `index.html` locally to review the design. All navigation, assets, and the CV work locally.

## Edit

- `index.html`: introduction, current research, appointments, selected papers.
- `research.html`: research themes, patent applications, service.
- `publications.html`: the six selected publications supplied in the CV.
- `styles.css`: responsive layout, colours, typography.
- `assets/akarsh-cv.pdf`: supplied CV, unchanged.

Content is based on the supplied CV. The current appointment follows that CV. No portrait was supplied, so the sidebar uses initials; replace them with a photo if desired. The Scholar URL in the CV was incomplete, so this version uses DBLP and ORCID. Publication links use only DOI identifiers supplied in the CV. Patent entries are labelled applications.
